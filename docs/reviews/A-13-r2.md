## Findings

### Major 1. UA-sniffing inline script for font preloads should be replaced by no preloads (V2)
V2 meets the ticket's rule: CLS 0, one request per face in chromium, webkit and mobile-webkit, no warnings, arrival delay below 150 ms. It removes UA sniffing, the extra inline script (one more CSP hash for `write-vercel-json`), and the noscript duplicate. V1 works but is more fragile and costs more than it gains.
Required change: delete the inline script and noscript in `src/layouts/Base.astro` (and the `fontUrls` constant if unused); relax `e2e/a02-tokens-fonts.spec.ts` assertions that expect preload links (check what it asserts); keep `e2e/a13-fonts.spec.ts` (it still guards one request per face and no unused-preload warning).

### Minor 1. Fallback faces depend on locally installed fonts
`Fraunces Fallback` uses `local('Georgia')`, `JetBrains Mono Fallback` uses `local('Menlo')`. Measured on macOS where both exist. On Linux/Android these are absent and the CLS guarantee in design §2.2 is not proven by this run. Add `local('Georgia')` alternatives for other platforms or accept; worth a note when the lhci CLS budget is checked on Linux CI.
