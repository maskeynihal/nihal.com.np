## Findings

### Major 1. Font preloads are not used by WebKit on any page (wasted preload, warning not gated)
Repro (Playwright WebKit, 6 s idle, `dist` served both by `pnpm preview` and by a static server sending `Cache-Control: immutable` on fonts): `/`, `/404.html` and `/sent/` all log, for both fonts, "preloaded using link preload but not used within a few seconds from the window's load event". The network log shows each woff2 requested twice (once by the preload, once by the @font-face), so the preload is not matched in WebKit. Chromium logs nothing. So the implementer's "intermittent" warning is a timing artefact: the console guard only sees it when a test stays open past WebKit's timer. It is not caused by the new A-13 pages (it affects `/` too), but it is a real defect in the A-02 preload strategy, and it is now visible in this harness. It is currently neither fixed nor in `e2e/console-allowlist.txt` (empty), so a longer WebKit test will flake. Fix by making the preload match (check the `crossorigin` value, `type`, and that the @font-face `src` URL is byte-identical, including any `unicode-range` subsetting effect on WebKit), or, if it is an unavoidable WebKit quirk, allowlist the exact message pattern in `console-allowlist.txt` with a reason, scoped, and note the double download.

### Minor 1. Allowlist selector match is a loose substring
`targets.some((t) => t.includes(e.selector))`: an entry with selector `img` would exempt any node whose target string contains "img" (e.g. `#imgfoo`). Prefer exact match of the target string or document that the value is a substring.

### Minor 2. 404 description wording
"The desk is one click away." is an invented closer. Copy §3 gives the 404 page only "That page moved or never existed." Voice rule 4 (no paragraph ends on a punchline) and the §2 reviewer-only zinger-ending check apply loosely: it is cute and leans on the "desk" metaphor. Suggest dropping it, e.g. "That page moved or never existed. The desk has the rest." is no better; use "That page moved or never existed." plus a factual tail, or keep the body line alone (needs >20 chars, so add "Nihal Maskey's site." style fact). Not blocking (noindex page, no-ship meta).

### Minor 3. sent description
"Your message is sent. I'll reply from contact@nihal.com.np." Spec §3 text is "Sent. I'll reply from ..."; the added "Your message is sent." is redundant but clean (no banned words, no em dash).

### Minor 4. `<head>` injection of `<base>`
No-js path does `.replace('<head>', ...)`. It works for Astro output (bare `<head>`), but silently does nothing if the head ever gets attributes, which would break relative CSS and so colour-contrast results. Use a regex on `<head\b[^>]*>`.
