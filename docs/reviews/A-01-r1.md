### Findings (code)
- Minor 1: TS 6 pin rationale undocumented. Add a line to docs (e.g. the A-11 README or `docs/process`) so Renovate/humans do not bump to 7.
- Minor 2: `tseslint.config()` is deprecated in typescript-eslint 8.x (typecheck prints a ts(6387) hint on `eslint.config.js`, 0 errors/warnings). Switch to `defineConfig` from `eslint/config` when convenient.
- Minor 3: palette is declared twice (`:root` vars in tokens.css and `--color-*` in `@theme`), so values can drift. A-02 owns "tokens.css + @theme"; consider `@theme inline` referencing the vars there.
- Minor 4: `Base.astro` loads Fraunces and JetBrains Mono from Google Fonts. Contradicts design spec §2.2 (self-hosted, no third-party) and will conflict with the CSP in A-09. Scaffold-level placeholder; must be removed by A-02. Not a blocker for A-01 (ticket does not require fonts).
- Minor 5: tailwind preflight resets h1 to 16 px, so the name renders small, top-left. Acceptable for scaffold; type scale is A-02.
- Minor 6: `.claude/launch.json` is tracked and points at a session scratchpad path. Not in the A-01 commit; consider untracking.
