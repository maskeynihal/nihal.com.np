## Findings

### Major
**M1. `check-initial-graph` ignores inline module scripts, so a leak can pass.** `htmlEntries` only collects `<script type=module src=...>`. Astro inlines small hoisted scripts: the real `dist/index.html` already contains `<script type="module">{...}</script>` (the hooks script). Proof: a scratch dist whose index.html has `<script type="module">import "/assets/mid.js";</script>` (mid.js re-exports desk-vendor-abc.js, which contains `REVISION`) prints `check-initial-graph: ok`, exit 0. Once E-01 lands, a bundled small entry that statically imports the desk vendor chunk would be inlined and missed. Fix: parse inline module script bodies with es-module-lexer and queue their static imports (and add a fixture).

**M2. `pnpm review` ID regex rejects real ticket IDs.** `/^[A-Z]-\d{2}$/` rejects `B-06a`, `B-06b` (both exist in tickets.md; the DoD requires `pnpm review <ID>` for them) and exits 2 (verified: `pnpm review B-06a` exit 2). Fix: `/^[A-Z]-\d{2}[a-z]?$/`.

### Minor
- m1. Missing referenced file is silently skipped (`if (!existsSync(file)) continue;`). A dangling modulepreload or import passes. Prefer to fail or warn.
- m2. `FORBIDDEN_NAME` is tested against the absolute path, so a checkout under a directory containing "physics" would false-positive. Test the path relative to dist.
- m3. `webServer` runs `pnpm preview` and does not build, and `reuseExistingServer` is true locally. Running `playwright test` directly serves whatever `dist` is there (plain build lacks hooks, so the smoke fails, which is loud but confusing). The `pnpm review` wrapper is correct; document that it is the only supported entry, or make the webServer command build first.
- m4. lighthouserc omits the §10 LCP <= 2000 and TBT <= 150 assertions, and performance is `warn` rather than `error`. Not in the A-08 text; add in E-11/F-02 or now.
- m5. Ticket calls for `playwright install --with-deps` in CI; no `.github` exists yet. It must land in A-07's ci.yml (carry over).
- m6. Spec §11 names the namespace `window.__desk`, the ticket says `__hooks`. Harmonise the spec text.
- m7. island attribute `before-hydration-url` not followed (low risk).
