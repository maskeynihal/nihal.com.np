# Plan critique 02: engineering, 2026-11-05

Reviewer: independent principal-engineer subagent. Targets: design §4-9, impl spec, tickets, review loop. Verdict: architecture sound; four things will not work as written, plus Majors that each cost a review round.

## Blockers
B1 **Lazy physics boundary blanks the desk and remounts every GLB.** `<Physics>` suspends until `RAPIER.init()`; `Suspense fallback={null}` hides the desk for the whole download; objects remount under `RigidBody` (new GPU uploads, settle drop). Fix: one static tree owns the Object3D instances in a registry; the physics layer **reparents imperatively** in `useLayoutEffect` (copy world pose into body, `group.add(obj)`, `body.sleep()`), cleanup reparents back. Explicit `objects.ts` body defs (id, home pose, primitive collider, mass, target section). Never `colliders="cuboid"` auto (would wrap occluder and line meshes separately).
B2 **`EdgesGeometry` cannot outline round objects** (cylinders at 16 segments = 22.5° seams; silhouettes are view-dependent). Fix: three passes: (1) occluder `MeshBasicMaterial` blue, polygonOffset 1/1, `toneMapped:false`; (2) **inverted hull silhouette**: same geometry, `side: BackSide`, white, vertex shader pushes along normal by screen-constant amount (`onBeforeCompile`, ~15 lines); (3) **authored creases** exported from Blender as a `LINES` primitive in the GLB (GLTFLoader yields `LineSegments`). `EdgesGeometry` 40° only for grey-box boxy objects.
B3 **CSP blocks WASM, preview analytics, form post.** Needs `'wasm-unsafe-eval'` (rapier + meshopt), `https://va.vercel-scripts.com` on previews, `form-action https://formspree.io`, `style-src 'unsafe-inline'` (Astro inline styles), `worker-src blob:`. Nonces impossible on static; use hashes, generated by a postbuild script that reads `dist/index.html` and writes `vercel.json`. Load analytics via bundled `inject()` with DNT check, not the component. Pac-Man sandbox `allow-scripts allow-same-origin` is correct only because the game is cross-origin on github.io.
B4 **Process depends on a Playwright suite scheduled last.** New **A-08 test harness** in Epic A: 6 projects, console-fail fixture + allowlist, `PUBLIC_TEST_HOOKS=1` build mode, `pnpm review <ticket>` runner. Each ticket adds its own spec. F-01 shrinks to flake pass + baselines.
B5 **Rapier 600 KB budget likely unattainable** (`rapier3d-compat` base64 WASM ≈ 650-800 KB gz). Fix: **E-11 spike** measures; or alias to `@dimforge/rapier3d` real `.wasm` with a shim; physics loads only on intent so it never touches LCP/TBT.

## Major
M1 **Fat lines**: `LineSegments2` + `LineMaterial` (`linewidth 1.5`, `worldUnits:false`, `resolution` on resize, `alphaToCoverage`, `toneMapped:false`). Pre-blend white@85% over blue to an opaque colour; no material opacity. R3F Canvas defaults to ACES tone mapping: pass `flat`. Tighten `near 0.5 / far 8`. Colour test tolerance ±2. Prefer `alpha:false` + `setClearColor(BLUE)` so canvas and occluder are identical by construction. `line.raycast = () => {}`; raycast occluders only.
M2 **Hidden poster hotspots under canvas = invisible focus trap.** Poster gets `inert` when canvas active; the object list is the single keyboard path on all viewports, visible on `:focus-within`, always on phones.
