## Findings

### Minor 1. CLS test skip is broader than its reason
`e2e/a13-fonts.spec.ts:51-54` skips every project except desktop-chromium with "layout-shift entries are only asserted in desktop-chromium". mobile-android, reduced-motion and no-webgl are Chromium and support `layout-shift`; only the two WebKit projects genuinely cannot. The skip is honest as stated but not a technical limit; the 4-Chromium coverage would cost seconds. Optional: gate on `browserName === 'chromium'`. The no-js skip is justified (needs JS observer); the WebKit CLS gap should be named in the reason ("WebKit has no layout-shift entries").

### Minor 2. Fallback fonts are macOS-only (carry-over from r2 Minor 1)
`src/styles/fonts.generated.css:23,32` use `local('Georgia')` and `local('Menlo-Regular'), local('Menlo')`. The CLS test proves nothing on Linux CI (Georgia/Menlo missing -> no size-adjusted fallback, CLS test might shift or be vacuous). Mutation 3 shows the test is sensitive here on macOS only. Watch the first Linux CI run; if it flakes add `local('Liberation Serif')`-style alternatives or measure there.
